# AdPlug

> AdPlug is the Marketing Control Plane that connects Google Ads, LinkedIn Ads, Microsoft Ads, and Google Search Console to Claude, ChatGPT, Cursor, and other Model Context Protocol (MCP) compatible AI tools. PPC specialists and agencies plug their ad accounts in once, then run audits, reports, weekly checks, and previewed account changes from the AI they already use, instead of opening another dashboard.

Last updated: 2026-09-07.

## About

AdPlug is built by Daniel Popa, a performance marketer with 10+ years in PPC and $100M+ in managed ad spend, who runs a consultancy managing Google Ads and LinkedIn Ads accounts. The product is opinionated: read-only by default, write actions gated behind a preview-confirm-execute flow, every tool call recorded with user, account, action, parameters, and timestamp. Hosted, no servers to run. Full story at https://adplug.app/about.

## Capabilities

AdPlug provides MCP (Model Context Protocol) tools for:

- **Google Ads**: List accounts and MCC hierarchy, query campaigns and ad groups, audit search terms, generate keyword ideas and forecasts, run custom GAQL queries, preview account changes, and manage negative keywords and shared sets.
- **LinkedIn Ads**: List accounts, review campaigns and creatives, inspect audiences and conversions, estimate audience size, look up targeting before committing, prepare account changes, and send up to 5,000 conversion events per call.
- **Microsoft Ads**: List accounts including manager accounts, run 20 report types (auction insights, LinkedIn profile demographics, change history, period comparisons), research keywords, create and edit search, Performance Max, Audience Network, and Dynamic Search Ads campaigns, set targeting including LinkedIn profiles, manage audiences, conversion goals, offline conversions, and conversion value rules, apply or dismiss Microsoft's recommendations, run up to 100 changes in one previewed batch, and copy Google Ads Search campaigns into Microsoft Ads.
- **Google Search Console** (its own connector, https://api.adplug.app/mcp/google-search-console): List properties with permission and type, with a 28-day summary of up to 50 properties in one call, run any Search Analytics report (queries, pages, countries, devices, search appearance, dates and hours; web, image, video, news, Discover, and Google News; regex filters; previous-period and year-over-year comparisons), run fourteen server-side analyses (overview, anomalies matched to Google ranking updates, declining pages and queries with their causes, striking distance, CTR opportunities, cannibalization, new and lost queries, brand split, CTR shift, page and query breakdowns, Core Web Vitals from Chrome UX Report data, and paid vs organic with Google Ads search terms, Performance Max included), inspect up to 25 URLs per call next to a live fetch with what changed since the last inspection, audit sitemaps with an estimated indexed share, and preview then apply sitemap submissions and removals and property additions and removals. Google has no API for Request indexing on normal pages, so AdPlug doesn't offer it.

Read tools are on by default. Write tools gate behind a preview-confirm-execute flow, so the AI shows the exact API call before it runs.

- Run a search-terms audit on the last 30 days. Flag the highest-spend terms with zero conversions and prep them as negative keywords. Preview before adding.
- Compare my LinkedIn Ads cost per lead against Google Ads paid search for the same offer over the last 90 days.
- Pause every responsive search ad with CTR below 1.5% and impressions over 1,000 in the last 7 days. Preview before executing.
- Generate keyword expansion ideas for my top three ad groups, commercial intent only.
- For client X, generate the slide deck data for our quarterly business review: CPA trend, search term wins, keyword expansion plan.
- Pull spend, CPA, and ROAS for every customer ID in MCC 123-456-7890 over the last 30 days.
